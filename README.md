# OLW

The published build of **Our Little World** — a small handcrafted top-down
adventure game, played on a phone held sideways.

Everything here is generated. The game's source lives elsewhere and is not
part of this repository; `index.html` is a single self-contained file with the
code, maps, tilesets and sprite sheets baked into it.

To update it, run `npm run deploy` in the source project.
